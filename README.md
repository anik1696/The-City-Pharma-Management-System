# City Pharma Management System

A web-based pharmacy management system that handles inventory, point-of-sale, customer records, and drug interaction checking — all in one interface.

---

## Overview

Built as a course project, this system is designed to simplify day-to-day operations of a pharmacy. Staff can manage medicine stock, process sales, check for known drug interactions, and view reports through a dashboard.

## Features

- **Dashboard** — sales summary, stock alerts, and visual charts
- **Inventory Management** — add, update, and track medicines with expiry dates
- **Point of Sale (POS)** — process transactions and generate invoices
- **Customer Management** — maintain customer records and purchase history
- **Drug Interaction Checker** — check if two medicines have known interactions
- **Reports** — view sales and stock reports

## Run Locally

**Requirements:** Node.js 18+

```bash
# Clone the repository
git clone https://github.com/anik1696/The-City-Pharma-Management-System.git
cd The-City-Pharma-Management-System

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at `http://localhost:5173`
